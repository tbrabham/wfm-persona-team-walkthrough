What's actually deciding this

  • Smallest set that adds value. The Desk only calls a specialist when the question needs that specific capability — it never runs the full team by reflex.
  • Numbers = cube, rationale = template. Stu pulls every figure cube-direct; Casey never renders a number Stu or Sara hasn't verified.
  • Model tier follows judgment, not volume. Sara is always Opus — low volume, high judgment, accuracy is the whole value. Michael, Stu, and Casey default to Sonnet and escalate to Opus only when a fetch or render turns into a judgment call (multi-source synthesis, ambiguous mapping, exec-sensitive framing).
  • Personas check each other. Sara re-verifies Stu's pull and Michael's context; Casey checks framing with Sara before rendering.
  • A monthly forecast review always runs the full pipeline — that's a standing standard, not a per-task decision.
